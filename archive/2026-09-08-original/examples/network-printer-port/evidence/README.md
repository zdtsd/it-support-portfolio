# Evidence guidance: network printer port case

No evidence file is included in this starter example. Don't fabricate a screenshot.

Useful evidence for a participant's own sanitized case could include:

- a cropped before-and-after comparison of port **types**, with names and addresses removed;
- a short reconstructed table showing affected versus known-good settings;
- a cropped queue result showing a completed test job, with printer and user identifiers removed;
- a photo of a test page only when its headers, identifiers, and surrounding environment are safe; or
- a typed verification record stating the test, timestamp category, and observed result.

Before committing evidence:

- remove printer names, addresses, workstation names, usernames, paths, and job metadata;
- crop unrelated windows, tabs, taskbars, notifications, and documents;
- avoid raw PowerShell output when a short sanitized table proves the same point;
- explain what the evidence proves and what it doesn't prove; and
- obtain instructor or peer review.
