# Project summaries

Use this folder for multi-step work with a goal, plan, deliverables, decisions, testing, and a final result. Examples may include a workstation refresh, a small deployment, an approved network build, or a documentation package.

## Demo entry

- [Windows workstation security baseline review](windows-security-review/README.md) shows scope, planning, five control checks, a priority decision, an approved change, and repeated verification.

This is an illustrative demo. Replace it with personal work after review.

## Add a project

Copy [the project-summary template](../templates/PROJECT-SUMMARY.md). Keep the scope accurate, record only the decisions that shaped the result, distinguish individual and team contributions, and link to no more than two strong sanitized deliverables in a normal entry.
