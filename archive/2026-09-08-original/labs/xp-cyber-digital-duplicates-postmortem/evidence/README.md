# Evidence Guide

## Public reference used for this demo

The structure of this post-mortem was informed by the publicly shared [Digital Duplicates XP Cyber Challenge Submission Report](https://github.com/wel51x/NICE-Challenges/blob/main/Digital%20Duplicates/5.%20Digital%20Duplicates.pdf).

The reference report remains in its owner's repository. This starter does not copy the PDF, reproduce the participant's name, or reuse the report's verification identifiers.

## What the submission report supports

The reference report provides direct evidence of:

- the challenge and submission timestamp;
- the recorded full-check result;
- the challenge duration;
- the mapped NICE task, KSA identifiers, work role, and specialty area; and
- a QR-linked verification mechanism using the report UID and submission ID.

The report does not prove the wording of a participant's reflection or every technical action taken during the exercise. The participant should write the post-mortem from personal experience and keep claims within the evidence.

## How a participant adds their own report

1. Download the official submission report from the participant's own XP Cyber account.
2. Confirm that the participant owns the report and is intentionally choosing to share it.
3. Review the name, duration, result, QR code, submission ID, and other visible fields.
4. Choose a public or private repository with the instructor. Use separately approved access-controlled storage when the report needs narrower visibility than the portfolio.
5. Save the approved file in this evidence folder with a descriptive name such as `xp-cyber-submission-report.pdf`.
6. Link the local PDF from the entry's Evidence section.
7. Open the committed PDF from GitHub and confirm that it renders and its verification path works as expected.

Do not substitute another participant's report. Do not add range screenshots, supplied files, commands, paths, or solution instructions to make the entry appear more detailed.

## Recommended evidence note

When a participant adds an owned report, use a short note such as:

> This XP Cyber-generated submission report records my challenge result and its report-supplied workforce mappings. I intentionally chose to share it as portfolio evidence. The accompanying reflection is my own work and excludes reproducible solution steps.

## What stays private

- Range credentials and account information
- Environment-specific commands and paths
- Supplied challenge materials
- Screenshots of the live workspace
- Instructor guidance or solution steps
- Raw notes that reveal a reproducible completion path
