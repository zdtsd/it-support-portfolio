Use this folder for completed help-desk tickets and troubleshooting exercises that contain enough reasoning to become full entries.

- [Diagnose a system that starts and shuts down](system-startup-diagnosis/README.md) shows symptom reproduction, safe internal inspection, a supported root cause, and repeated startup verification.

## Add a case

1. Copy [the ticket case-study template](../templates/TICKET-CASE-STUDY.md) into a descriptive folder such as `cases/network-printer-offline/README.md`.
2. Explain why each important check was selected and how the result changed the next decision.
3. State what you personally did and what another participant or instructor did.
4. Verify the original function before calling the case resolved.
5. Add only reviewed, sanitized evidence.

A worklog row is enough for routine or repetitive work. Create a full case study when the activity shows useful troubleshooting, communication, escalation, uncertainty, or learning.
