# Evidence Guide

No hardware image is included in this demo. A participant could add:

- a tightly cropped, de-identified photo of the corrected fan connection if photography was approved;
- an original cable-path diagram with generic labels;
- a sanitized two-start verification checklist; or
- reviewer feedback confirming the diagnosis and safe procedure.

Review photos for serial numbers, asset tags, labels, badges, reflections, screens, nearby paperwork, and unrelated equipment. A participant-created diagram is usually safer than a wide workbench photo.
