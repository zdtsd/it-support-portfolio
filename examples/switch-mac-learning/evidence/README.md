# Evidence guidance: switch MAC-learning lab

No evidence file is included in this starter example. Don't copy a full switch configuration or fabricate terminal output.

Useful sanitized evidence from a participant's own lab could include:

- a simple participant-created topology diagram with generic device and port labels;
- a short before/move/after table showing one sanitized MAC and two generic interfaces;
- cropped terminal output containing only the relevant dynamic MAC entry, with prompts and device names removed;
- a configuration excerpt limited to the two approved lab interfaces; or
- a verification checklist recording link, VLAN, learned interface, cable move, new traffic, and relearned interface.

Before committing evidence:

- remove management addresses, credentials, prompts, device names, serial numbers, and unrelated interfaces;
- replace the workstation MAC with a clearly documented locally administered example;
- exclude production configuration and instructor-only staging or reset methods;
- explain what the evidence proves about source learning and what it doesn't prove; and
- have the sanitized derivative reviewed separately from any raw capture.
