# Evidence Guide

No diagram or packet capture is included in this demo. Useful participant evidence could include:

- an original DORA flowchart with generic client and server labels;
- a cropped worksheet section that contains no participant or course-system identifiers;
- a participant-created message-state table; or
- review feedback confirming the protocol explanation.

A real packet capture needs careful review for addresses, hostnames, hardware addresses, user traffic, and unrelated protocols. Use a redrawn conceptual diagram when the capture can't be safely published.
