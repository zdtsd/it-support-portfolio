# Evidence Guide

No screenshot or terminal capture is included in this demo. A participant could add reviewed evidence such as:

- a cropped command window showing a harmless `dir` result from the practice folder;
- a short, sanitized excerpt showing the selected diagnostic command;
- the participant's original command decision table; or
- instructor feedback confirming the reasoning and correction.

Remove usernames, device names, internal addresses, directory paths, unrelated windows, and account details before committing evidence. Re-type a short result in the report when a screenshot can't be sanitized confidently.
