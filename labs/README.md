# Lab reports

Use this folder for structured hands-on labs. A useful report explains what the result proves. A list of commands or clicks can't provide that explanation by itself.

## Demo entries

- [Windows command-line troubleshooting decisions](command-line-troubleshooting/README.md) explains command selection, safe practice, and tool limits.
- [DHCP DORA process analysis](dhcp-dora-analysis/README.md) connects each message with a lease-state change and states the limits of a conceptual flow.

These are illustrative demos. Replace them with personal work after review.

## Add a lab

Copy [the lab-report template](../templates/LAB-REPORT.md) into a descriptive folder. Document the starting condition, procedure, expected and observed results, verification, technical explanation, personal contribution, and sanitized evidence.

For team labs, identify your own configuration, testing, observation, or documentation work separately from the team's combined result.
