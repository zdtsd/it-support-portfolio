# Turn a ticket or XP Cyber challenge into a short write-up

Pick work you can explain in your own words. Read [the printer example](write-ups/printer-offline.md) or [the XP Cyber example](write-ups/xp-cyber-customer-support.md) to see how much detail is enough. Aim for **100–200 words in about 5–10 minutes**; the word count is a guide.

## Write your first entry

1. Open your own portfolio repository on GitHub. Your instructor can help you set one up.
2. Copy the text from [WRITEUP-TEMPLATE.md](WRITEUP-TEMPLATE.md). From your repository's main page, choose **Add file → Create new file** and name it something like `write-ups/my-printer-fix.md`.
3. Paste the template and replace the prompts. Explain the problem, what you found, your reasoning, the result, and the skills you used. Keep the setting accurate and give credit for help you received.
4. Read it once for clarity. Leave out names, real ticket numbers, private system details, and passwords. Screenshots are optional; only include ones checked for private information.
5. Use **Preview**, then **Commit changes** to save your work. Follow your instructor's review process if your repository uses one. See [GitHub's file creation guide](https://docs.github.com/en/repositories/working-with-files/managing-files/creating-new-files) for help.
6. Add a link and a short result to the selected work table in your main [README](README.md).

A useful explanation connects an action to a reason: “Comparing with a working computer helped me narrow the problem to one device.” If the fix wasn't confirmed, say so. An escalation can show good judgment too.

For XP Cyber, summarize the challenge and one or two useful decisions. Leave out solution steps, commands, exact settings, and answers. You can link your own completion report if you've checked it for private information; describe only the outcome it actually records.

## Add framework connections if useful

Choose a few relevant items from the [framework reference](FRAMEWORK-MAPPINGS.md) for the expandable section at the end. Explain the connection in a short phrase. The examples show how; your instructor can help select the mappings. You can remove that section and still have a complete write-up.

## Make the portfolio yours

Change the README title to your name and write one or two sentences about your IT interests and training. Replace the example rows with your own links, then remove the example notice and sample write-ups. Keep just your work in the table before sharing it with a hiring manager.

Start with one write-up. Add another when it shows a different skill. The README and your write-ups are all you need to maintain.
