# IT & Cyber Support Portfolio

Short write-ups from support tickets and XP Cyber challenges, showing CompTIA concepts in practice: understanding a problem, choosing useful checks, and testing the result.

> **Example portfolio:** These illustrative write-ups use a participant's voice. They aren't records of participant completion. Replace them with work you personally completed.

## Selected work

| Ticket or challenge | Skills in practice | Result |
| --- | --- | --- |
| [One computer couldn't print](write-ups/printer-offline.md) | Printer settings, comparing configurations | Corrected the connection setting and printed a test page |
| [Websites wouldn't load](write-ups/websites-not-loading.md) | Network checks, DNS, browser settings | Corrected a browser connection setting and tested two websites |

## Add your own work

Pick a ticket or XP Cyber challenge you worked on and spend about **5–10 minutes** writing **100–200 words**. Explain the problem, your reasoning, and the outcome. Each example also has an expandable note connecting the work to workforce frameworks.
