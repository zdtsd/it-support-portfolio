## Writing a useful row

- Use the completion date in `YYYY-MM-DD` format.
- Use a searchable activity title without a real ticket number or requester name.
- State a result you verified. "Completed the lab" doesn't explain the result.
- Link to a full entry with a relative Markdown link when the activity deserves more detail.
- Describe uncertain or incomplete outcomes accurately.
